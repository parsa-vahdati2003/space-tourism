# 🚀 Space Tourism Website

A responsive space tourism website built to explore destinations, crew members, and space travel technology through a modern and immersive user interface.

## 🌐 Live Demo

**[Click here to visit the Space Tourism Website](space-tourism-xi-virid.vercel.app)**


## 🛠️ Technologies Used

- **HTML5** — Structuring the web pages
- **CSS3** — Styling and layout
- **Tailwind CSS** — Utility-first styling and responsive design
- **JavaScript (ES6+)** — Interactive features and dynamic content
- **Axios** — Handling HTTP requests and data fetching
- **Vite** — Development server and build tool

## 📱 Responsive Design

The website is fully responsive and optimized for three screen sizes:

- 💻 **Desktop / Laptop**
- 📱 **Tablet**
- 📲 **Mobile**

The layout adapts to different screen sizes to provide a smooth and consistent user experience across devices.

## ✨ Features

- Modern space-themed user interface
- Interactive destination pages
- Crew member information
- Space technology section
- Responsive navigation menu
- Dynamic content rendering with JavaScript
- Responsive layouts for desktop, tablet, and mobile devices

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/parsa-vahdati2003/space-tourism.git
   ```

2. Navigate to the project directory:

   ```bash
   cd space-tourism
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
